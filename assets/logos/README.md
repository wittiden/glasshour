# Service logos

A small selection of **white monochrome SVG icons** for the quick-link tiles.

Icons are sourced from [Simple Icons](https://simpleicons.org/) and released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Brand names and logos
remain trademarks of their respective owners.

The SVGs are already `#ffffff`, so they work on the dark glass tiles without changes.
The existing `.link__logo img` rule also normalizes images to white.

## Usage

Replace the placeholder icon in `index.html`:

```html
<span class="link__logo">
  <img src="assets/logos/github.svg" alt="">
</span>
```
